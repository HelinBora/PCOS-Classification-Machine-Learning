# PCOS Classification Using Machine Learning Algorithms

## Project Overview
This project analyzes and classifies PCOS (Polycystic Ovary Syndrome) data using fundamental machine learning algorithms in MATLAB.

## Objective
To compare the performance of traditional ML algorithms in medical dataset classification.

## Algorithms Used
- Support Vector Machine (SVM)
- K-Nearest Neighbors (KNN)
- Decision Tree
- Logistic Regression

## Dataset
PCOS dataset containing hormonal and clinical parameters.

## 📈 Evaluation Metrics
- Accuracy
- Precision
- Recall
- Confusion Matrix

## 🛠 Technologies
- MATLAB
- Statistics and Machine Learning Toolbox
